# Ecommerce-Data-Analysiss
E-commerce data cleaning and analysis using Python, Pandas, SQL, and Power BI to prepare data and support business insights.

E-commerce Data Cleaning and Analysis

Project Overview

This project focuses on cleaning and preparing e-commerce data using Python, SQL, and Power BI. The goal is to improve data quality and prepare the data for business analysis and visualization.

Tools and Technologies

Python – Data cleaning and data processing

Pandas & NumPy – Data manipulation and handling missing values

MySQL – Storing and managing cleaned data

Power BI – Creating interactive dashboards

Jupyter Notebook – Writing and executing Python code

Project Workflow

Loaded the e-commerce dataset into Python.

Checked for missing values and duplicate records.

Replaced invalid values and removed extra spaces.

Standardized customer names, cities, and states.

Validated email addresses and converted date and numeric columns.

Handled missing values and removed invalid quantities.

Created new columns such as Sales, Net Amount, Profit, Month, Year, and Weekday.

Exported the cleaned data to a CSV file.

Connected Python to MySQL and stored the cleaned data in a database.

Used Power BI to create a dashboard for data visualization.

Files Included

ecommerce.ipynb – Python notebook containing the data cleaning and processing steps.

CLean_Ecommerce.csv – Cleaned e-commerce dataset.

ecommerce.pbix – Power BI dashboard file.

Learning Outcomes

Learned how to clean and prepare real-world style datasets.

Practiced data manipulation using Pandas and NumPy.

Learned how to connect Python with MySQL.

Practiced preparing data for Power BI visualization.

Conclusion

This project helped me practice the data analysis workflow, from data cleaning and database storage to dashboard creation.
